## 🚀 Overview

A personal developer portfolio designed with a futuristic Tron/Cyber aesthetic, sleek dark mode visuals, animated circuit boards, dynamic laser scanlines, and smooth scroll animations. Built with Next.js 15 App Router, React 19, TypeScript, and Framer Motion.

---

## ✨ Features

- **⚡ Cyber / Tron Visual Aesthetic**: Glowing neon accents (crimson, orange, red), dark glassmorphism surfaces, animated circuit nodes, and scan lines.
- **🖱️ Interactive Custom Cursor**: Trailing cursor with hover reactivity and micro-animations.
- **🎬 Rich Motion & Scroll Transitions**: Powered by Framer Motion for scroll reveals, 3D card tilt effects, particle systems, and dynamic typewriter animations.
- **📱 Fully Responsive**: Optimized for ultra-wide displays, laptops, tablets, and mobile screens.
- **💻 Showcase Sections**: Detailed showcases for featured projects, technical competencies, academic background, and industry certifications.

## 💻 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18.17 or later) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/febin-d/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   pnpm install
   # or
   yarn install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Visit [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Building for Production

```bash
npm run build
npm run start
```
